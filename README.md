# EVIL ELITE TRADING PLATFORM

![Evil Elite Trading](public/og-image.png)

> **Next-generation institutional-grade derivative trading engine. Execute high-frequency trades with institutional precision.**

## 🌐 Overview
EVIL ELITE is an elite, high-performance SaaS platform built for professional traders. It goes beyond generic dashboard metrics to provide an immersive, institutional-feeling terminal.

The core philosophy of the platform: *Trading is not gambling or guessing; it is data ingestion, statistical probability, and ruthless mechanical execution.*

## ⚡ Core Features
- **Secure Operator Dashboard**: A cinematic, Bloomberg-inspired dark-mode terminal.
- **Trader Gamification Engine**: Built-in psychological retention systems tracking Discipline Streaks, Operator Levels, and XP.
- **Trading Journal & Ledger**: A secure ledger for tracking setups, emotions, execution mistakes, and cumulative PnL equity curves.
- **AI-Powered Trade Reviews**: A foundation built for automated screenshot and note analysis, grading operator execution.
- **Community Hub**: Global network features including Leaderboards, Activity Feeds, and encrypted Profiles.
- **Encrypted Checkout Flow**: Institutional Stripe-powered gateway for subscription allocations and digital asset deliveries.

## 🛠 Tech Stack
- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Data Visualization**: [Recharts](https://recharts.org/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Payments**: [Stripe](https://stripe.com/)
- **Mailing**: [Resend](https://resend.com/)
- **Database/Auth**: [Supabase](https://supabase.com/)

## 🚀 Getting Started

First, ensure you have the required environment variables in `.env.local`:
```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=your_stripe_pub_key
STRIPE_SECRET_KEY=your_stripe_secret_key
RESEND_API_KEY=your_resend_key
```

Then, run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to initialize the secure node.
